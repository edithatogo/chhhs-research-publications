# Grant source ingestion

Deliver small independently testable official RSS/Atom/API adapters and the existing canonical reviewed-upsert path. Reuse normalisation, schema and source-health contracts; separate publication flows from grants and keep unrelated sources independently recoverable. Historical HTML-calendar adapter fixes are preserved as history only: HTML scraping is retired.

Acceptance requires canonical opportunity/round keys, whole-observation history, precedence and review preservation, full-page accounting and failure isolation. A zero-row result must be classified as verified-empty or failed/incomplete before accepted data changes. Real opportunity admission needs official row provenance and native list/model readback; local fixtures cannot establish a live source or unattended service.

Follow the [hardened completion contract](../../../docs/PLATFORM_COMPLETION_PLAN.md#hardened-completion-contract), [RIMS grants experience](../../../docs/RIMS_GRANTS_EXPERIENCE.md) and [delivery review](../../../docs/GRANTS_DELIVERY_REVIEW.md). The task IDs, dependency gates, exact inputs and expected evidence are in [the implementation plan](plan.md). Reuse existing resources and keep actual tenant/account identities, payloads, credentials and run evidence in ignored private storage. No local test closes a native gate.
