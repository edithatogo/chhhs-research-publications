## Field meanings

| Field | Meaning |
|---|---|
| SourceKey | `opencitations:<DOI>`; one source assertion per selected DOI |
| SourceID / RelatedID | Exact DOI / `doi:<DOI>`; no person or organisation inference |
| ContextKind | `publication_enrichment_assertion` |
| CitationObservation | Full provider count response, request, headers and its observed UTC time |
| MetadataObservation | Full metadata response and its independently observed UTC time |
| CountArchive / MetadataArchive | Original raw filename and SHA256; existing files are reused |
| MetadataDisposition | Single match, no hit or unadjudicated multiple matches |
| SourceProjectionJSON | Complete combined source observation, preserving unknown provider fields |
| SourceProvenanceJSON | Metadata capture, raw source/hash, combined manifest and scope; count time remains separate |

The accepted48 metadata responses contain44 single matches, three no-hits and one
multiple match. Do not choose an arbitrary record from a multiple match or treat
a no-hit as proof that the work does not exist. Citation counts are provider and
time specific, must not be summed across providers and are not measures of quality.
The combined scope identifies membership and provenance, not a common observation
time. Earlier reused count observations retain their earlier timestamps.
